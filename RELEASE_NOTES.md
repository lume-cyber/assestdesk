# Assetdesk 1.1.0

Portable self-hosted release for Python 3.12+ and Docker Compose.

Included features:

- Separate application accounts and multiple administrators
- Per-list Viewer and Editor permissions
- Spreadsheet import from XLSX and CSV
- Private asset pictures with authenticated access
- Service and assignment/return history
- Search, filtering, CSV export, lifecycle fields, and audit events
- Guided configuration for any hostname
- Docker, cPanel/Passenger, and standard WSGI deployment paths

No database, credentials, secrets, uploaded pictures, or organization-specific configuration are included in the release archive.
